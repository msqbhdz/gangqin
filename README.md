# 🎹 网页钢琴 · Web Piano

一个纯前端、零依赖的 **88 键网页钢琴**，支持手机与电脑，可直接部署到 GitHub Pages。

## ✨ 功能

- 🎹 **88 键全音域**：可横向滑动 / 缩放浏览，手机上点按即弹
- ⌨️ **键盘弹奏**（电脑）：白键 `Z X C V B N M` + `A S D F G H J K L ;` + `Q W E R T Y U I O P`，黑键 `1 2 3 4 5 6 7 8 9 0 - =`，按住 `Shift` 整体升一个八度
- 🎼 **曲库跟奏**：内置 7 首曲目（小星星 / 两只老虎 / 欢乐颂 / 生日快乐 / 铃儿响叮当 / 送别 / 卡农），支持「试听」与「跟奏」两种模式
- 📊 **实时评分**：跟奏时给出音符准确率、节奏合律度、最长连奏，支持调速（0.5×–1.5×）、暂停、重奏
- 📈 **演奏记录**：本地保存最近 30 条（仅存于本机浏览器，不上传）
- ⚙️ **设置**：主音量、显示音名、低动效模式、使用教程

## 🎵 音色

采用 **Web Audio API 实时合成**钢琴音（多谐波叠加 + 指数衰减包络），无需联网、无需加载任何采样文件。

## 🚀 部署到 GitHub Pages

1. 把本仓库推到 GitHub（见上方 `gangqin` 仓库）
2. 打开仓库 **Settings → Pages**，在 **Build and deployment** 下选择：
   - Source：**Deploy from a branch**
   - Branch：**main**，目录 **/ (root)**
   - 保存
3. 稍等约 1 分钟，访问：**https://msqbhdz.github.io/gangqin/**

> 仓库已开启 Pages，可直接访问上述链接。

## 🛠 技术栈

- 纯 HTML / CSS / JavaScript，单文件 `index.html`
- 无任何外部依赖，离线可用
- 响应式设计，适配手机 / 平板 / 桌面

## 📱 手机使用提示

- 点按琴键发声，左右滑动或点 `◀ ▶` 切换音域
- iOS 首次点击会唤醒音频（浏览器安全策略，正常现象）
- 跟奏面板在顶栏下方，含分数与谱面提示

## ⚖️ 曲目说明

内置曲目均为公版 / 传统 / 简化旋律，仅用于学习演示。
